# 微信提审材料清单

更新时间：2026-07-11

## 账号与资质

- [ ] 小游戏账号、正式 AppID、主体认证和管理员权限。
- [ ] 游戏类目与实际玩法一致。
- [ ] 备案申请完成并获得可展示信息。
- [ ] 实名、防沉迷、适龄提示及所需前置审批完成专项核对。
- [ ] 客服邮箱、电话、隐私联系人和投诉处理流程可用。

## 产品材料

- [ ] 正式名称及两个备用名称完成商标与近似名称排查。
- [ ] 图标、启动图、分享图、五张竖屏截图和玩法简介。
- [ ] 审核说明写清教程、订单、制作、店铺修复和激励广告触发位置。
- [ ] 审核账号或无需账号即可进入的审核路径。
- [ ] 隐私指引、用户协议、第三方 SDK 清单和权限说明。

## 技术门禁

- [ ] 正式 AppID 构建，不含 `touristappid`。
- [ ] 微信开发者工具冷启动、前后台、断网和清缓存测试通过。
- [ ] 3 台 Android、2 台 iPhone 和 1 台低内存设备通过。
- [ ] 云档冲突、广告中断、棋盘满格、制作未完成退出和跨日刷新通过。
- [ ] 主包低于 4 MB，分包和远程资源下载失败可恢复。
- [ ] 崩溃、启动、教程、首单、广告和存档异常可观测。

## 素材权属

- [ ] 每张 AI 素材保留提示词、日期、原始文件、最终文件和修改记录。
- [ ] 不使用竞品名称、角色、美术、UI 截图、文案或数值表述。
- [ ] 字体、音效、音乐及第三方库许可证单独归档。
- [ ] 最终提交素材经过人工复核，不含错误文字、水印和近似品牌元素。
